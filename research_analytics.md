# Official Project Analytics Findings

Source: https://manus.im/docs/website-builder/project-analytics

The official Manus Project Analytics documentation states that live Manus-built sites receive integrated tracking without requiring third-party analytics setup. It identifies these visitor metrics: **Visitors** (unique users over a period), **Page Views** (total pages viewed), and **Traffic Sources** (such as direct, search, or social). It also notes that authenticated sites can show users who signed in.

The documentation categorizes this capability under **Website Builder → Project Management → Project Analytics**. The public Manus website was not authenticated during inspection, so the exact navigation labels of an individual user’s project interface were not directly visible.
