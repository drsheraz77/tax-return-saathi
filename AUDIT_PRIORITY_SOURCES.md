# Priority Feature Source Record

The limited Tax Year 2026 source foundation added in this feature batch uses three official FBR starting points reviewed on **26 August 2026**. FBR’s filing guidance describes IRIS access, registration, return completion, filing, record keeping, and privacy; the due-date page lists published category-level due dates; and the laws index is a navigation point for current primary material. These sources support a preparation map only. They do **not** establish a user-specific deadline, eligibility, calculation, or filing outcome.

| Topic | Official starting point | Intended in-product purpose |
|---|---|---|
| Filing workflow | [FBR: File Income Tax Return](https://www.fbr.gov.pk/categ/file-income-tax-return/51147/80860/71158) | Verify current IRIS, filing, record-keeping, and support routes. |
| Published due-date categories | [FBR: Income Tax due dates](https://www.fbr.gov.pk/categ/income-tax-due-dates/51147/40846/81148) | Check the currently published category before acting. |
| Laws index | [FBR: Acts / Ordinances / Rules](https://www.fbr.gov.pk/act-rules-ordinances/131226) | Locate current primary legal material for further verification. |
